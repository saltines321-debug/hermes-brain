🧠 Hermes Brain

A public, zero-knowledge template for a modular agent skeleton.

Hermes Brain is a starting point for building your own brain logic — not a hosted platform or a distributed orchestration service. It ships the architecture and guardrails of an agentic system: a minimal core decision loop, capability hooks, a policy gate, and append-only memory — without embedding private history, learned behavior, or tuned configuration.

Key features

  • Modular skeleton — a minimal core loop (brain.py) plus capability hooks you can extend (capabilities/).
  • Policy gate — runtime and privacy rules that are safe by default (allow_external_actions: false, retain_private_memory: false, redact_sensitive_fields: true).
  • Append-only memory — decisions and outcomes are logged to memory/outcomes.jsonl, one JSON object per line.
  • Template vs. Sync modes — keep memory/ private per agent, or commit and share it intentionally across instances.
  • Public / private split — clean structure and guardrails ship publicly; private runtime state stays out of the template.

Quick start

git clone https://github.com/saltines321-debug/hermes-brain.git
cd hermes-brain
python3 brain.py

This reads any JSON in inbox/ and writes a decision report to outbox/decisions.json.
